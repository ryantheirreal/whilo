# Whilo — arquivo de conversa e documentação

Este diretório preserva a conversa de planejamento disponível nesta sessão, o histórico de eventos compactado pelo Manus e uma cópia dos Markdown existentes no repositório no momento do arquivamento.

## Conteúdo

- `manus-conversation-events.jsonl`: arquivo bruto de eventos compactados da sessão.
- `CONVERSATION-INDEX.md`: índice humano dos pedidos, decisões e entregas.
- `markdown/`: cópia organizada dos Markdown do repositório, mantendo seus caminhos relativos.

Os arquivos originais continuam nos locais usados pelo build. Esta cópia é um arquivo de contexto e não deve ser usada como fonte de runtime.
