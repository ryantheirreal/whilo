As imagens abaixo são referências visuais para estudo de composição, hierarquia, mascote, onboarding, chat, status e permissões. Elas não são assets de produção do Whilo. Validar licença e atribuição antes de reutilizar qualquer imagem fora deste board.

## Regras de uso

1. A imagem é referência, não componente de produção.
2. A marca Whilo deve usar seus próprios assets, mascote e sistema visual.
3. O próximo passo de cada referência é uma hipótese testável, não uma cópia.
4. Preferir componentes acessíveis, responsivos e compatíveis com teclado/screen reader.
5. Registrar fonte, licença e decisão no PR que usar a inspiração.
